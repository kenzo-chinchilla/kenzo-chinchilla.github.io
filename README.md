# Kenzo Chinchilla – Portfolio

Personal portfolio site, hosted with GitHub Pages.

## How to publish

1. On GitHub, create a new **public** repository named exactly `kenzo-chinchilla.github.io`.
2. Upload `index.html`, this `README.md`, and the `assets` folder.
3. Add your résumé PDF to the repo as `Kenzo_Chinchilla_Resume.pdf`.
4. Go to **Settings → Pages**, set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. After a minute or two, the site is live at https://kenzo-chinchilla.github.io

## Adding photos

Put images in the `assets` folder with these names, and they’ll appear automatically:

| File | What to show |
|---|---|
| spo2-board.jpg | Best photo of the finished SpO2 board (shown at the top of the site) |
| spo2-schematic.png | KiCad schematic screenshot |
| spo2-layout.png | KiCad PCB layout or 3D view |
| spo2-working.jpg | Board showing a live reading |
| macro-layout.png | Macro keyboard PCB layout |
| macro-assembly.jpg | Mid-soldering photo |
| macro-finished.jpg | Finished keyboard |
| drone-detection.jpg | A frame with a drone detected |

Any missing image shows a gray box telling you what to add. Keep photos under ~1 MB each so the page loads fast.
