DIY SpO2 Pulse Oximeter

  • KiCad
  • Arduino Nano
  • MAX30102
  • OLED
  • I2C
View code on GitHub

What I built

A handheld pulse oximeter on a custom PCB. An Arduino Nano reads red and infrared light measurements from a MAX30102 optical sensor over I2C, calculates blood-oxygen saturation and heart rate, and shows the results in real time on an OLED display.

How I designed it

I took the board from schematic capture through component placement and trace routing in KiCad. Some parts weren’t in the standard libraries, so I created custom footprints for them, then generated Gerber files to have the board fabricated.

Result

I hand-soldered every component, then tested and debugged the assembled board into a fully working device.

FMCW Radar Simulator

  • MATLAB
  • Signal processing

Goal

Simulate a 77 GHz FMCW radar that detects and tracks up to five moving targets. The simulator generates linear chirps (150 MHz bandwidth, 128 chirps per frame) and models echoes with propagation delay, Doppler shift, and noise.

Processing pipeline

Range and Doppler FFTs produce a range-Doppler map, 2D CA-CFAR picks out real targets from the noise floor, and a Kalman filter tracks each target across frames. Performance will be compared across SNRs from −10 to 20 dB.

Pulsed Radar Signal Processor

  • Verilog
  • GTKWave
  • Digital design

Goal

An RTL radar processor that takes in 12-bit samples at 10 MHz, filters noise with a 16-tap fixed-point FIR filter, and detects echoes from up to three targets using threshold and peak detection, then converts echo delay into range (15 m per sample).
